Core Banking Capabilities

Engineered for Robust Financial Operations

Built from the ground up to demonstrate full-stack engineering standards, safe transactional state changes, and defensive coding principles.

ACID Money Transfers

Utilizes MySQL transactions (START TRANSACTION, COMMIT, ROLLBACK) to guarantee sender debits and receiver credits execute atomically.

Simulated Deposits & Withdrawals

Deposit demo money with instant balance replenishment or execute cash withdrawals with strict overdraft protection and zero negative balances.

Real-Time Audit Trail

Every deposit, withdrawal, and transfer automatically generates a unique audit reference number, immutable date, running balance snapshot, and CSV export.

Automatic Account Generation

Customer registration automatically checks duplicates, hashes credentials via bcrypt, and assigns a unique 10-digit demo bank account number with a $1,000 bonus.

CSV Statement Export

Download clean, comma-separated financial statements directly to your computer with one click for easy spreadsheet auditing.

Fully Responsive UI

Designed with a premium banking palette (Navy, Royal Blue, Soft Grey) that scales cleanly across mobile, tablet, and desktop viewports.

Security Architecture

Enterprise-Grade Defensive Design

Security is not an afterthought in this application. Multiple layers of defense protect customer data and transaction integrity.

Bcrypt Salted Password Hashing

Passwords are never stored in plain text. Stored hashes use 10 salt rounds with adaptive cost protection.

HTTP-Only Signed Session Cookies

Sessions are stored server-side with httpOnly: true and sameSite: 'lax' to mitigate XSS cookie theft and CSRF attacks.

Parameterized SQL Queries

Every database interaction uses prepared statements via mysql2/promise, completely immunizing the system against SQL injection.

Brute-Force Rate Limiting

Login endpoints are guarded with express-rate-limit to thwart automated password guessing bots.
