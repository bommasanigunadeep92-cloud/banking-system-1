ACID Transaction Protocol
Every fund transfer is safeguarded by strict database guarantees:
  • Row Locking: Both sender and receiver accounts are locked with FOR UPDATE to prevent race conditions.
  • Double Entry: Deducts sender balance and increments receiver balance simultaneously.
  • All-or-Nothing: If any single SQL statement fails, MySQL performs a complete ROLLBACK. Money is never lost or duplicated.
